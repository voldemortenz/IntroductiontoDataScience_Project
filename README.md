PROJECT: KAGGLE - Stroke Prediction

Authors: Voldemar Kirss, Tormi Arne Raidvere

Team code: H7

This github repository features the different files for the project in UT course LTAT.02.002 Introduction to Data Science. 

Stroke is the 2nd leading cause of death globally, responsible for approximately 11% of total deaths. Thus it is important to correctly identify patients who are likely to suffer a stroke so that they could get the healthcare they need.

The goals of this project were to perform a descriptive analysis of the dataset and use different machine learning algorithms to predict whether or not a patient will suffer a stroke.

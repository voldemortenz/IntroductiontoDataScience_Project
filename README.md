This github repository features the different files for the project in UT course LTAT.02.002 Introduction to Data Science. 

Stroke is the 3nd leading cause of death globally, responsible for approximately 11% of total deaths ([1]). Thus it is important to correctly identify patients who are likely to suffer a stroke so that they could get the healthcare they need.

The goals of this project were to perform a descriptive analysis of the dataset and use different machine learning algorithms to predict whether or not a patient will suffer a stroke.

File healthcare-dataset-stroke-data.csv is the dataset file which has 5110 rows (ie patients) and 13 health and various different indicators, for example age, sex, bmi, work type.

File xxx is the main analysis code which features the statistical analysis and the use of different machine learning algorithms.

File xxx is the poster which gives a short synopsis on the project.

The main analysis code is commented and the analysis can be reproduced according to the contents in this file.
